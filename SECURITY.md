# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private security advisory form:

https://github.com/freestylefly/WeChatBridge/security/advisories/new

Include the affected version or commit, reproduction steps, expected impact, and any suggested mitigation. Please keep technical details private until a fix is available.

## Scope

Security reports may cover the main macOS app, Share Extensions, local archive handling, clipboard behavior, update verification, permissions, and release artifacts.
